# Litoveleiros

Projeto Next.js com App Router e JavaScript, pronto para publicar na Vercel.

## Rodar localmente

```bash
npm install
npm run dev
```

Depois, abra `http://localhost:3000`.

## Funcionamento

A página possui um título, uma frase, uma caixa de texto, um botão **Analisar** e uma área de resposta. Ao clicar em **Analisar**, o mesmo texto digitado aparece na área de resposta.
