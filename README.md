# Litoveleiros

Projeto Next.js com App Router e JavaScript, pronto para publicar na Vercel.

## Estrutura

- `app/page.js`: página principal
- `app/layout.js`: layout global
- `app/styles.css`: estilos
- `package.json`: dependências e scripts

## Rodar localmente

```bash
npm install
npm run dev
```

Depois abra `http://localhost:3000`.
